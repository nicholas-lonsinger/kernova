# Contributing to Kernova

Kernova is **source-available** under the [Functional Source License (FSL-1.1-ALv2)](LICENSE): the source is public so you can read, audit, and build it, and the project does not accept outside code contributions. The license reserves commercial-licensing rights, so accepting contributed code would take a Contributor License Agreement, and none exists.

- **Bug reports and feedback are welcome** — please [open an issue](https://github.com/nicholas-lonsinger/kernova/issues).
- A pull request from outside the project may be closed without review.
